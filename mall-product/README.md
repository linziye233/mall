# mall-product 商品服务模块

## 模块概述
商品服务是电商微服务平台的核心模块之一，主要负责商品信息管理、秒杀商品查询、库存管理等业务功能。该模块针对**高并发、高性能、高可用**（三高）场景进行了深度优化。

---

## 三高场景技术方案总结

### 一、高并发（High Concurrency）优化方案

#### 1. **多级缓存架构**
采用三级缓存策略，逐层降低数据库压力：

- **L1 - JVM本地缓存（Guava Cache）**
    - 使用 `LocalCache` 组件，基于 Guava Cache 实现
    - LRU淘汰策略，最大容量500条
    - 写后60秒过期
    - 优势：纳秒级响应，无网络开销

- **L2 - Redis分布式缓存**
    - 存储商品详情JSON数据
    - 1小时基础过期时间 + 0-300秒随机偏移（防止雪崩）
    - 支持空值缓存（60秒），防止缓存穿透

- **L3 - 数据库（MySQL）**
    - 作为最终数据源
    - 仅在缓存未命中时访问

**代码位置**: `ProductCacheService.java`

#### 2. **布隆过滤器防穿透**
- **Redis布隆过滤器**: `BloomRedisService`
    - 拦截不存在商品的请求
    - 避免大量无效请求打到数据库

- **本地JVM布隆过滤器**: `LocalBloomFilter`
    - 基于 Google Guava BloomFilter
    - 容量100万，误判率1%
    - 快速过滤非法商品ID

**拦截器**: `BloomFilterInterceptor` 在请求到达Controller前进行校验

#### 3. **分布式锁保护**
两种分布式锁实现，应对不同场景：

- **Redis分布式锁**（推荐）
    - 基于 `SETNX + UUID` 实现
    - Lua脚本保证原子性释放
    - 锁超时时间5秒，防止死锁
    - 双重检查机制（DCL）

- **ZooKeeper分布式锁**
    - 基于临时节点实现互斥锁
    - 监听节点删除事件唤醒等待线程
    - 使用 `CountDownLatch` 实现阻塞等待
    - 适用于强一致性场景

**代码位置**:
- `ProductCacheService.java` (Redis锁)
- `ZKLockImpl.java` (ZK锁)

#### 4. **降级与容错策略**
- **锁竞争降级**: 未获取锁的线程等待50ms后从Redis读取
- **缓存失效降级**: Redis异常时直接查数据库
- **超时保护**: 所有缓存操作设置超时时间

### 二、高性能（High Performance）优化方案

#### 1. **缓存预热机制**
- `LoadSeckillProduct2Cache` 组件
- 应用启动时将秒杀商品加载到Redis
- 减少冷启动时的数据库冲击

#### 2. **批量查询优化**
- 支持根据多个商品ID批量获取促销信息
- 减少网络往返次数

#### 3. **分页查询优化**
- 使用 PageHelper 进行物理分页
- 秒杀列表默认每页10条，限制单次查询数据量

#### 4. **序列化优化**
- 使用 Fastjson 进行JSON序列化
- 相比原生Java序列化性能提升3-5倍

#### 5. **连接池配置**
- Redis连接池: commons-pool2
- 数据库连接池: HikariCP（Spring Boot默认）

---

### 三、高可用（High Availability）保障方案

#### 1. **缓存雪崩防护**
- **随机过期时间**: `CACHE_EXPIRE_SECONDS + random.nextInt(300)`
- 避免大量key同时过期导致数据库压力突增

#### 2. **缓存穿透防护**
- **布隆过滤器**: 前置拦截非法请求
- **空值缓存**: 对不存在商品缓存"EMPTY"标记60秒

#### 3. **缓存击穿防护**
- **分布式锁**: 热点key重建时加锁
- **双重检查**: 获取锁后再次检查缓存
- **互斥重建**: 同一时刻只有一个线程查询数据库

#### 4. **故障隔离**
- **本地缓存兜底**: Redis故障时使用JVM缓存
- **数据库直连降级**: 所有缓存失败时直接查DB
- **异常捕获**: 各层级独立try-catch，单点故障不影响整体

#### 5. **监控与健康检查**
- Spring Boot Actuator 集成
- Nacos 服务注册与发现
- 日志追踪: SLF4J + Logback
